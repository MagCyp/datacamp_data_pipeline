# E-commerce Data Pipeline

A simple ETL pipeline built with Python and pandas.

The project:
- extracts grocery sales data,
- cleans and transforms the dataset,
- calculates average weekly sales by month,
- exports cleaned and aggregated data to CSV files,
- validates that the output files were created successfully.

## Tools

- Python
- pandas
- SQL

## Output

- `clean_data.csv`
- `agg_data.csv`
